# 🎨 Generate Random Color 

A simple and responsive web project to generate random colors using HTML, CSS, and JavaScript.

---

## 🌐 Live Demo

🔗 https://karansinh1818.github.io/RGB-Reactor/ 

---

## 📌 Project Description

This project is a basic random color generator.  
Clicking the button generates a new RGB color and updates both the heading and the color box dynamically.  

---

## 🚀 Features

- Generate Random RGB Colors
- Display current color code in the heading
- Dynamic background color change in the color box
- Smooth hover effect on the button
- Fully responsive design for mobile and desktop

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
